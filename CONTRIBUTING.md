# Contributing to UI Design Skill

Thank you for your interest in contributing to the **UI Design** skill (`@ravizikrillah/ui-design`)!

We welcome contributions to expand design principles, refine anti-slop rules, update web interface guidelines, and improve testing methodologies.

---

## 🎯 How You Can Contribute

1. **Anti-Slop Rules Enhancement**: Suggest additions or clarifications to the 38-rule catalog in `references/anti-slop-rules.md`.
2. **Framework & Design System Templates**: Add new starters or expand `templates/DESIGN.md` for modern design systems.
3. **Web Guidelines**: Keep accessibility and interaction patterns aligned with modern W3C/WCAG standards in `references/web-interface-guidelines.md`.
4. **Documentation & Fixes**: Fix typos, improve examples, or clarify agent instructions.

---

## 🛠️ Contribution Workflow

1. **Fork or Branch**:
   Create a descriptive branch:
   ```bash
   git checkout -b feat/your-improvement
   ```

2. **Make Changes**:
   Follow clean formatting standards:
   - No generic AI slop or placeholder code.
   - Use clear markdown structure.
   - Keep references organized.

3. **Open a Pull Request**:
   - Provide a clear summary of what was added or changed.
   - Reference any relevant issues or design discussions.

---

## 📄 Code of Conduct

Please maintain a collaborative, respectful, and constructive environment for all contributors.
